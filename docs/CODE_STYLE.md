# 💻 Code Style

> Padrões oficiais de código do Abrigo.

---

# Objetivo

Garantir que todo o projeto siga o mesmo padrão de desenvolvimento.

---

# JavaScript

Preferir:

- const
- let

Evitar:

- var

---

# Componentes

Sempre utilizar:

PascalCase

Exemplo

```
GlassCard.jsx

Navbar.jsx

UserAvatar.jsx
```

---

# Hooks

Sempre iniciar com:

```
use
```

Exemplo

```
useTheme()

useCalendar()

useJourney()
```

---

# CSS

Utilizar nomes claros.

Exemplo

```
.card

.card-title

.card-content
```

Evitar:

```
.box1

.div2
```

---

# Funções

Utilizar nomes descritivos.

Bom

```
loadUser()

saveMood()

calculateStatistics()
```

Ruim

```
run()

test()

abc()
```

---

# Arquivos

Componentes

```
PascalCase
```

Hooks

```
camelCase
```

Utils

```
camelCase
```

Services

```
PascalCase
```

---

# Comentários

Comentar apenas quando necessário.

Código limpo vale mais que muitos comentários.

---

# Linhas

Evitar funções muito longas.

Sempre que possível dividir responsabilidades.

---

# CSS

Preferir:

Flexbox

Grid

Variáveis CSS

---

# React

Prioridades

- Componentes pequenos
- Hooks personalizados
- Reutilização
- Performance

---

# Imports

Organizar nesta ordem:

1. React

2. Bibliotecas

3. Shared

4. Módulo

5. Services

6. Utils

7. CSS

---

# Boas práticas

✔ Código simples

✔ Código reutilizável

✔ Componentes pequenos

✔ Nomes claros

✔ Organização

✔ Performance

✔ Acessibilidade

---

# Regra Final

Sempre escreva código pensando que outra pessoa precisará entendê-lo no futuro.
