# Contexto do Projeto

Projeto:

Abrigo 2.0

Objetivo:

Criar uma plataforma para organização da vida pessoal.

O Abrigo reúne funcionalidades como:

- Diário
- Cartas
- Humor
- Hábitos
- Metas
- Calendário
- Estatísticas
- Jornada
- IA

O projeto prioriza:

- simplicidade
- acolhimento
- privacidade
- segurança
- organização

A arquitetura do projeto está documentada em:

docs/ARCHITECTURE.md

O Design System está em:

docs/DESIGN_SYSTEM.md

Toda alteração deve seguir esses documentos.
