# Regras

Antes de escrever qualquer código:

✔ Ler a documentação.

✔ Seguir a arquitetura.

✔ Seguir o Design System.

✔ Seguir o Roadmap.

✔ Seguir o Code Style.

Nunca:

- duplicar código
- quebrar arquitetura
- criar componentes gigantes
- ignorar responsividade
- ignorar acessibilidade

Sempre:

- reutilizar componentes
- criar código legível
- manter organização
- documentar mudanças importantes
